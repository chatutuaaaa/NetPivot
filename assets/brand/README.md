# NetPivot 图标

四个节点由一条简洁的路径连接成字母 N，呼应 NetPivot 与多设备虚拟组网。节点表示设备，连接线表示虚拟网络；图形不规定真实网络必须采用链式拓扑。

| 文件 | 用途 |
| --- | --- |
| netpivot-icon.svg | 完整方形底色版，图标矢量母版 |
| netpivot-mark.svg | 透明背景标志，适合浅色页面 |
| netpivot-monochrome.svg | 单色版，适合印刷或单色界面 |
| netpivot-icon.png | 1024×1024 栅格导出，可供后续图标资产制作 |
| netpivot-preview.png | 不同尺寸及颜色方案的预览 |

颜色：深蓝 `#102A43`、青绿 `#39DCC3`、浅白 `#F4FAFC`。

SVG 仅包含路径与圆形，不依赖字体、外部图片、脚本或网络资源。所有版本使用相同的 1024×1024 坐标，避免缩放时比例变化。

正式图标母版不预先裁圆角；具体 App 图标资源与当前 Xcode 的要求在打包阶段核对。预览中的圆角仅用于展示效果。PNG 是 SVG 的栅格导出，并非已经接入完成的 Xcode AppIcon 资源包。
